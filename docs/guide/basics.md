
# Getting Started

Apps for Windows93 can be created on Windows93 itself, using CodeMirror, Notepad or any similar text editor, or on your own system.

Get started by learning to [create a program](../guide/making-app), or reading about the [internals](/docs/internals/indexeddb).

## Resources

- These docs
- [Builtin Apps](https://github.com/win93-community/programs)
- [Discord Server](https://discord.gg/bYFhRTMmMK)
- [theme.html](https://windows93.net/theme.html) and [theme.js](https://windows93.net/theme.js)
- [Component demos](https://windows93.net/42/docs) (make sure to check "Show code")

## Beginners, read this!

You need to have a basic understanding of JavaScript and HTML in order to create programs for Windows 93. If you don't know JavaScript, HTML or any programming fundamentals, take a few hours to learn the basics.

This guide will walk you through how to create an app.

**Your best resource is looking at the [builtin apps](https://github.com/win93-community/programs).** Send a message in the [discord](https://discord.gg/bYFhRTMmMK) if you need help.
